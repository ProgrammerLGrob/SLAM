A ROS 2 package implementing a visual odometry pipeline for a mobile robot equipped with a Kinect RGB-\/D camera. ...\hypertarget{index_autotoc_md3}{}\doxysection{\texorpdfstring{visual\+\_\+odom}{visual\_odom}}\label{index_autotoc_md3}
A ROS 2 package implementing a visual odometry pipeline for a mobile robot equipped with a Kinect RGB-\/D camera. The system detects ORB keypoints in incoming RGB frames, lifts them into 3D using registered depth data, and estimates frame-\/to-\/frame motion via RANSAC Kabsch alignment. Pose estimation is embedded in a Rao-\/\+Blackwellized particle filter\+: each particle maintains its own landmark map and an EKF per tracked landmark. The best particle is selected by log-\/likelihood weight. The resulting pose is broadcast as a TF transform and published as a {\ttfamily nav\+\_\+msgs/\+Odometry} message.

Implements the Extended Kalman Filter for tracking an individual landmark position in the odom frame. The state vector is a 3D Coordinate {\ttfamily (x, y, z)}.

{\bfseries{Measurement model}}

The expected measurement transforms the landmark from odom into the robot\textquotesingle{}s local frame using the current heading rotation\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{h(x)\ =\ R(theta).T\ *\ (x\_landmark\ -\/\ x\_robot)}

\end{DoxyCode}


{\bfseries{Noise model}}

The measurement covariance R is depth-\/dependent, propagated from pixel-\/space noise to baselink\+:


\begin{DoxyCode}{0}

\end{DoxyCode}

\hypertarget{index_autotoc_md21}{}\doxyparagraph{\texorpdfstring{robot.\+py}{robot.py}}\label{index_autotoc_md21}
Represents a single particle in the Rao-\/\+Blackwellized particle filter. Each particle maintains its own {\ttfamily Visual\+Odom\+Map}, {\ttfamily Extended\+Kalman\+Filter\+Robot}, and accumulated pose. All particles receive the same RANSAC result computed centrally by {\ttfamily Visual\+Odom} and apply it independently.

\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}{\ttfamily robot\+\_\+iteration(...)}\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}

The per-\/frame update sequence for one particle\+:


\begin{DoxyEnumerate}
\item On first iteration\+: seed the landmark map until {\ttfamily INITIAL\+\_\+\+LANDMARK\+\_\+\+COUNT} is reached.
\item Apply the RANSAC delta pose to the particle position with optional Gaussian noise.
\item Query {\ttfamily get\+\_\+visible\+\_\+landmarks()} for landmarks in the current camera FOV.
\item Match visible landmark descriptors against current frame descriptors via BFMatcher.
\item Run {\ttfamily landmark\+\_\+kalman\+\_\+iteration()} on all matched landmarks.
\item Compute {\ttfamily log\+\_\+weight} via {\ttfamily calculate\+\_\+log\+\_\+weight()}.
\item Run {\ttfamily cleanup\+\_\+old\+\_\+landmarks()}\+: increase trust for matched landmarks, decay others, remove landmarks below {\ttfamily MIN\+\_\+\+LANDMARK\+\_\+\+TRUST}.
\item Add unmatched keypoints as new landmarks if match count is below {\ttfamily MATCHES\+\_\+\+FOR\+\_\+\+NEW\+\_\+\+LANDMARKS}.
\end{DoxyEnumerate}

\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}{\ttfamily predict\+\_\+with\+\_\+wheel\+\_\+odom(state\+\_\+wheel\+\_\+odom)}\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}

Main ROS 2 node ({\ttfamily Visual\+Odom}). Orchestrates the particle filter, runs RANSAC between consecutive frames, and broadcasts the pose of the best particle as TF.

{\bfseries{Initialization}}

Parameters are loaded from the ROS 2 parameter server, backed by {\ttfamily \doxylink{param_8yaml}{param.\+yaml}}. A {\ttfamily cv2.\+ORB} detector and {\ttfamily cv2.\+BFMatcher} (NORM\+\_\+\+HAMMING, cross\+Check) are created. N particles ({\ttfamily Visual\+Robot\+Sample}) are instantiated on the first valid RGB frame.
